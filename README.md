## 🌟 จุดเด่นของโปรแกรม
- **Standalone 100%**: ใช้งานได้ทันทีผ่าน Web Browser (แนะนำ **Microsoft Edge** หรือ **Google Chrome**)
- **ผูกกับเมมการ์ดจริง**: ผ่าน File System Access API อ่าน/เขียน/ลบไฟล์บนเมมจริง
- **จัดการ XML อัตโนมัติ**: บันทึก แก้ไข และตัดรายการใน `gamelist.xml` ของแต่ละโฟลเดอร์รอมอัตโนมัติ พร้อมระบบสำรองไฟล์ `gamelist.xml.bak`
- **รองรับ PSX ยกโฟลเดอร์**: เพิ่มและตรวจจับเกม PS1 แบบโฟลเดอร์ย่อย BIN+CUE ได้อย่างสมบูรณ์
- **ใส่ปกเกมแบบ Browse**: เลือกไฟล์รูปภาพจากคอมพิวเตอร์เพื่อตั้งเป็นหน้าปกเกมได้ทันที
- **🌐 ส่งออกโค้ด Google Sites (Embed Code)**: ส่งออกรายชื่อเกมและภาพปกเกม (Base64 JPEG ฝังในตัว) เพื่อนำไปฝังลง Google Sites หรือบันทึกเป็นไฟล์ HTML ได้ทันที

## 🚀 วิธีใช้งาน
1. เสียบเมมโมรี่การ์ดเข้ากับคอมพิวเตอร์ (เช่น ไดรฟ์ `E:`)
2. ดับเบิ้ลคลิกเปิดไฟล์ **`run_manager.bat`** หรือดับเบิ้ลคลิก **`RetroGameManager.html`**
3. กดปุ่มสีฟ้า **[📂 เชื่อมต่อเมมโมรี่การ์ด (Connect SD Card)]** ด้านบน
4. เลือกไดรฟ์เมมโมรี่การ์ดของคุณ แล้วกด **"เลือกโฟลเดอร์ (Select Folder)"** และกดยืนยันการอนุญาตสิทธิ์ (Allow / Edit Files)
5. เริ่มต้นจัดการเกมได้ทันที:
   - **➕ เพิ่มเกมใหม่**: กดปุ่ม [➕ เพิ่มเกมใหม่] ด้านบน เลือกได้ทั้งแบบไฟล์เดี่ยว (GBA, SFC ฯลฯ) หรือแบบยกโฟลเดอร์ (PSX BIN/CUE)
   - **🖼️ เปลี่ยนรูปปก**: กดปุ่ม [🖼️ ปก] บนการ์ดเกม แล้วเลือกรูปภาพจากเครื่อง
   - **🗑️ ลบเกม**: กดปุ่ม [🗑️ ลบ] บนการ์ดเกมที่ต้องการลบ
   - **🌐 ส่งออก Google Sites**: กดปุ่ม [🌐 ส่งออก Google Sites] เพื่อคัดลอกโค้ด HTML นำไปวางในเมนู [ฝัง (Embed)] ของ Google Sites ได้ทันทีพร้อมภาพปกครบถ้วน
