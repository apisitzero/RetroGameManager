## 📖 เกี่ยวกับโปรแกรม

**Retro Game & SD Card Manager** คือเว็บแอปพลิเคชันสำหรับจัดการเมมโมรี่การ์ด (SD Card / TF Card / พาร์ทิชัน EASYROMS) ของเครื่องเล่นเกมพกพาเรโทร (เช่น Anbernic, Miyoo Mini, Powkiddy, R36S, TrimUI, Batocera, ArkOS, AmberELEC ฯลฯ) 

ทำงานโดยตรงผ่าน **File System Access API** บนเว็บเบราว์เซอร์ ช่วยให้คุณสามารถอ่าน, แก้ไข, เพิ่มเกมใหม่, เปลี่ยนภาพหน้าปก, ลบเกมที่ไม่ต้องการ และจัดระเบียบฐานข้อมูล `gamelist.xml` บนเมมการ์ดจริงได้อย่างรวดเร็วและปลอดภัย โดยไม่ต้องติดตั้งโปรแกรมเสริมขนาดใหญ่

---

## 🌟 จุดเด่นและฟังก์ชันหลัก (Key Features)

- 🌐 **ใช้งานได้ทั้งแบบ Online และ Offline**:
  - **ออนไลน์ผ่าน GitHub Pages**: เปิดเว็บเบราว์เซอร์แล้วเชื่อมต่อจัดการเมมการ์ดได้ทันที
  - **ออฟไลน์บนคอมพิวเตอร์**: ดับเบิลคลิก `run_manager.bat` พร้อมระบบ Real-Time Drive Monitor
- 🎯 **ระบบตรวจจับไดรฟ์อัจฉริยะ (Scanned Drives Only)**:
  - ดรอปดาวน์แสดงเฉพาะไดรฟ์ที่สแกนเจอจริง ไม่แสดงไดรฟ์หลอก
  - สามารถสลับดูข้อมูลเกมและความจุระหว่างไดรฟ์ที่สแกนพบได้ทันที
- 🎮 **รองรับคอนโซลเรโทรครอบคลุมทุกระบบ**:
  - Sony PlayStation 1 (PS1 / PSX), PSP
  - Nintendo (GBA, GBC, GB, NDS, 3DS, SNES/SFC, NES/FC, N64)
  - Sega (Mega Drive / Genesis, Saturn, Dreamcast, Game Gear)
  - Arcade, Neo Geo, FBNeo, MAME, PC Engine, WonderSwan และอื่นๆ
- 📁 **รองรับทั้งเกมไฟล์เดี่ยวและเกมยกโฟลเดอร์**:
  - เพิ่มเกมไฟล์เดี่ยว (`.gba`, `.sfc`, `.nes`, `.chd`, `.zip` ฯลฯ)
  - เพิ่มและตรวจจับเกม PS1 แบบโฟลเดอร์ที่มีไฟล์คู่ `.bin` + `.cue` ได้อย่างสมบูรณ์
- 🖼️ **ระบบจัดการรูปหน้าปกเกม (Cover Art Manager)**:
  - อัปโหลดรูปหน้าปกจากคอมพิวเตอร์เข้าโฟลเดอร์ `images/` ของแต่ละคอนโซล
  - ค้นหาภาพปกเกมออนไลน์แบบเรียลไทม์
- 📝 **จัดการฐานข้อมูล `gamelist.xml` อัตโนมัติ**:
  - ซิงค์รายชื่อเกม, ชื่อที่แสดง, ภาพปก, ผู้พัฒนา, ประเภทเกม และสถานะเกมโปรด
  - มีระบบสำรองข้อมูลอัตโนมัติ `gamelist.xml.bak` ป้องกันไฟล์สูญหาย
- 📊 **แถบแสดงพื้นที่ความจุเมมโมรี่การ์ด**:
  - คำนวณและแสดงผลพื้นที่ว่าง (Free Space) และพื้นที่ที่ใช้ไป (Used Space) แบบเรียลไทม์
- 🌐 **ส่งออกโค้ดสำหรับ Google Sites (Embed Code)**:
  - สร้างโค้ดแสดงแดชบอร์ดรายชื่อเกมและภาพปก เพื่อนำไปฝังลงหน้า Google Sites ของคุณได้ในคลิกเดียว (รูปภาพฝังในตัว ไม่หาย 100%)

## 🚀 วิธีการใช้งาน

### ความต้องการของระบบ:
- เว็บเบราว์เซอร์ **Google Chrome** หรือ **Microsoft Edge** เวอร์ชั่นล่าสุด (เนื่องจากรองรับ File System Access API)

---

### ขั้นตอนการใช้งาน:
1. เสียบ **SD Card** หรือ **Flash Drive** เครื่องเกมเข้ากับคอมพิวเตอร์ (เช่น ไดรฟ์ `E:` หรือ `G:`)
2. เปิดโปรแกรม:
   - **กรณีใช้งานผ่านเว็บ (Online)**: เข้าสู่หน้าเว็บ GitHub Pages ของโปรแกรม
   - **กรณีใช้งานบนเครื่อง (Offline)**: ดับเบิลคลิกไฟล์ **`run_manager.bat`** หรือเปิด **`RetroGameManager.html`**
3. คลิกปุ่มสีฟ้า **[📂 เชื่อมต่อเมมโมรี่การ์ด]** ที่แถบเมนูด้านบน
4. เลือกโฟลเดอร์ไดรฟ์ของเมมโมรี่การ์ด (เช่น โฟลเดอร์ `EASYROMS` หรือไดรฟ์ `E:\`)
5. กดปุ่ม **"เลือกโฟลเดอร์ (Select Folder)"** และกดยืนยันการอนุญาตสิทธิ์ **"Allow"** หรือ **"ดูและแก้ไขไฟล์"**
6. ระบบจะสแกนโฟลเดอร์คอนโซลทั้งหมดและดึงรายชื่อเกมพร้อมภาพปกออกมาแสดงผลทันที!

---

### การจัดการเกมในระบบ:
- **ค้นหาเกม**: พิมพ์ชื่อเกม, คำว่า `thai` สำหรับเกมแปลไทย, หรือฟิลเตอร์เกมโปรด ⭐
- **เพิ่มเกมใหม่**: คลิกปุ่ม **[➕ เพิ่มเกมใหม่]** เลือกคอนโซล ใส่ชื่อเกม แนบไฟล์ ROM และเลือกภาพปก
- **แก้ไข/เปลี่ยนปกเกม**: คลิกปุ่ม **[🖼️ ปก]** บนการ์ดเกมเพื่อเปลี่ยนภาพหน้าปก
- **แก้ไขชื่อเกม**: คลิกปุ่ม **[✏️ แก้ไข]** บนการ์ดเกมเพื่อเปลี่ยนชื่อเกมใน `gamelist.xml`
- **ลบเกม**: คลิกปุ่ม **[🗑️ ลบ]** บนการ์ดเกมที่ต้องการลบออกจากเมมโมรี่การ์ด
- **ส่งออก Google Sites**: คลิกปุ่ม **[🌐 ส่งออก Google Sites]** คัดลอกโค้ด HTML นำไปวางในเมนู [แทรก ➔ ฝัง (Embed)] บน Google Sites ได้ทันที
